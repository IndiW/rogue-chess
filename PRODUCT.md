# Rogue Chess
A static pixel-art browser chess roguelike on GitHub Pages. The player controls White. Wins advance floors; draws replay with build progress. Defeat banks capture mastery and opens a random three-choice starting-relic pack, then resets to floor 1 with a fresh army. Captured pieces respawn each battle. All save data is local to the device.

## Progression
Individual starting-square identities retain XP and equipped upgrades between floors, including through promotion or Royal seed transformation. Captures give pawn1, minor3, rook5, queen9 XP; Scholar adds1. Packs at3/6/10 actual captures, max3 per piece per run. Capture value and Scholar affect mastery XP only. Existing earned packs survive migration. Earned packs open between battles after wins/draws; failed-run packs are discarded.

Each pack has two random, distinct, unlocked upgrades for its earning piece plus one random general item. Choose one and discard others. Revealed rolls are saved. Owned options are filtered out; passives replace their corresponding charged movement upgrade. There are36 upgrades: four base and two mastery-unlocked branches per piece type. Mastery thresholds8/20 unlock the advanced movement branch and Second Wind. Mastery persists after loss, restart or quit; equipped builds and inventory reset. Mastery banks once at battle end, and Hourglass restores uncommitted capture XP/packs to prevent duplicate rewards.

General loot is consumable inventory. A chosen starting relic refreshes each battle. Echo grants two same-piece moves (second may capture); Oracle recommends a move; Hourglass restores the prior turn and enemy reply; Royal seed changes a2 to a knight next battle. King's safety always applies, and giving check ends any extra turn. Momentum/Chain Jump's second move cannot capture. Second Wind doubles charged piece ability uses. See README and upgrades.js for the complete catalog.

## Run controls and timing
The main menu provides Start, Resume, Restart and Quit Run. Resume restores board/XP/charges/packs/clock. Menu pauses the live run; restart and quit confirm before discarding the run and retain mastery. Closing the page saves and pauses. Saved running clocks still use timestamps so background-tab throttling cannot grant time.

Each battle has180 seconds of player thinking time, no increment. The clock does not start until White makes the first actual move. Then it runs on White's turns, including powers, Oracle analysis and promotions; it pauses for Black, the menu and inter-battle rewards. Timeout is defeat. New battle resets clock; Hourglass never refunds time.

## Opponent
Stockfish.js17.1 lite single-threaded WASM handles ordinary positions. Floors1–11 raise skill0–20, depth caps4–24, and time limits250–2000ms. Oracle searches full skill up to2500ms. A shared-rule variant search handles positions with active movement powers/Echo, including extended knight attacks, charged escapes and extra turns. Its strength differs from Stockfish; the UI names the current backend. Standard engine failure falls back to lightweight JS; variant failures expose retry. Credits/GPL/source are linked in help.

## Presentation
Original pixel sprites, carved highlights and shadows. Time purple, Insight blue, Growth green, Movement amber, with text labels. Piece upgrade markers and selected-piece XP/charge panel. King topples for800ms before a full-width blue/gold CHECKMATE win ribbon or red defeat ribbon, then rewards/K.O. screen. Reduced motion supported. Mobile interactive controls use touch-action:manipulation to stop double-tap zoom while preserving pinch zoom. Original hosted MP3 chiptune defaults enabled after a gesture, preserving saved mute; independent Web Audio effects include pack/reward cues. Mobile-first fixed item slots and selected-piece powers sit above the board. A stable pack counter replaces the board-shifting notification. Between battles, a dedicated rewards screen shows totals, sealed packs, claimed rewards and next-floor inventory. Packs animate open before three choices appear; a brief selection animation locks the choice. All packs must be claimed before advancing.
