# Visual system
Experience mode: a dungeon chess table with an immediately playable central board. Moss and parchment pixel pieces, charcoal green surroundings, amber relics. Desktop: expedition path / board / inventory. Mobile: condensed run strip, full-width board, inventory below. Square geometry and authored pixel silhouettes establish the game world.

Tokens: background #161c19, surface #1d271f, text #e9e9d7, muted #9aab9c, amber #e6b968, board light #c5ccb0, board dark #657e59. DM Sans for UI, Space Grotesk for titles. Clear legal move dots, last move squares, oracle highlights, keyboard focus rings. No decorative motion; board updates communicate turns.
